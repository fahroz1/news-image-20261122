A one-page newspaper front page summing up the world's news of Sunday, 22 November 2026: the COP31 climate summit in Antalya collapsing without a deal, an Iranian strike on Bahrain and tanker attacks near the Strait of Hormuz, the first Trump–Xi–Putin trilateral summit in Shenzhen, Russian strikes on Ukraine, the capture of cartel boss "El Chapo Isidro" in Mexico, a global market sell-off led by AI shares, and the World Court finding Myanmar guilty of the Rohingya genocide. The page is drawn with plain shapes and set in a classic broadsheet style — ivory paper, near-black ink, and a single dark-red accent.

Run it with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies `entry.png` (1024×1024, under 1 MiB) to the output directory.
